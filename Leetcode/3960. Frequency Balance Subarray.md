## 3960. Frequency Balance Subarray
* Faces multiple TLE, key idea is using freq-of-freq map to look for max and min freq instead of iterating through cnt.items(). 
* SC: O(N)
```
'''
* Main takeaway: to find max freq or min freq, can use freq map

I was initially thinking of using priority queue to get the max and min, but it is not viable
The constraint is 1 <= nums.length <= 10**3 so this means that max(cnt.values()) can be O(N), final TC can be O(N**3)
Using freq constraint, TC can be (k * (k+1))/2 == n, TC approximately O(sqrtN), however we limit len(freq to be 2) so TC can be O(1) for this check 
final TC: O(N**2)
SC: O(N + 1) == O(N)
'''
class Solution:
    def getLength(self, nums: List[int]) -> int:
        cnt = Counter(nums)
        if len(cnt) == 1:
            return len(nums)
        ans = 1
        for l in range(len(nums)):
            cnt = Counter([nums[l]])
            # number of elements e having freq f
            freq = {1: 1}
            for r in range(l+1, len(nums)):
                old = cnt[nums[r]]
                if old:
                    freq[old] -= 1
                    if freq[old] == 0:
                        del freq[old]
                cnt[nums[r]] += 1
                new = cnt[nums[r]]
                if new in freq: 
                    freq[new] += 1
                else:
                    freq[new] = 1
                # now i am counting through every key-pair values which may be O(N)
                if len(freq) != 2:
                    continue
                if (max(freq.keys()) == min(freq.keys()) * 2):
                    ans = max(ans, r - l + 1)
        return ans
```
## GPT Takeaway:
### Pattern:
* If the validity condition depends on the distribution of frequencies,


### maintain:
* cnt[x]   = frequency of element x
* freq[f]  = number of elements with frequency f

* Updating both maps is often O(1), avoiding repeated scans of cnt.
