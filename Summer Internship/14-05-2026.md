### Harness engineering 
Not about doing writing better prompts but building an environment for AI to work in 
* give task
* agent reads harness files
    * instructions: not one giant instructions, but step-by-step guide
    * scope: one feature at a time
    * state: make sure states are saved to disk
    * verification: outputs have to be verified 
    * session lifecycle: initialise at start, clean up at the end
