## 3933. Largest Local Values in a Matrix II
Initially I tried bfs, but then faces TLE because TC = O(mn * mn)

## Model solution
* uses sparse table, record for each row
* st[r][c][k] = max(st[r][c][k-1], st[r][c + (1 << (k-1))][k-1]
* st[r][c][k] calculates range for [c, c + 2**k - 1]
