## Challenges in AI systems
* Scalability 
    * fan-out to multiple (Track scaling per model instead of per user because different models different loads)
    * cascading failures
    * latency (use priority queue for request, so that fast path model not blocked by small path model.)
    * heterogenous workloads
    * model cold-starts
* Observability 
* Cost optimisation
An interesting take: we are not building AI application, we are building a deterministic system for probabilistic components. Same like how UDP has packet loss problem and planes are built from components that may fail but guard rails are in place to handle the uncertainty.
