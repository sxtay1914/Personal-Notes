## Reading through codebase
* Purpose of refresh token: when access token expires, refresh token is used to obtain a new valid access token
* access token ≈ JWT
	
## Why access token lower TTL than refresh token?
* access token is exposed on the network, higher vulnerability thus have lower TTL
