## 1674. Minimum Moves to Make Array Complementary
### Initial approach:
* Tried binary search, failed to do because I search over the range [2, 2*limit] and increase the left pointer to find more optimal solution but this is wrong because I assume a monotonically decreasing trend towards the upper region.

### Model Sol:
* The key idea is difference array, for each a, b find the boundary for c where operation is 0, 1 & 2
then do prefix sum to find the c with minimal operation
* TC: O(n+L)

### Model Sol 2: 
* Binary Search, instead of searching over [2, 2*limit], the idea is to find how many pairs are less than c and how many pairs are less than c-limit. 
* TC: O(n log n + L log n)
